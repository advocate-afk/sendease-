🔗 Connect Your Gmail
One-time setup — takes about 3 minutes. After this, your emails go directly from your Gmail. Completely free via Google Apps Script.
Gmail connected
1
Open Google Apps Script
Go to script.google.com → Sign in with your Gmail → Click New Project
2
Paste the code
Select all text in the editor and delete it → Download Code.gs → Open it → Copy all → Paste in editor → Press Ctrl+S
Code.gs → Select All → Delete → Paste → Ctrl+S
3
Deploy as Web App
Click Deploy (top right) → New Deployment → Type: Web App → Execute as: Me → Who has access: Anyone → Click Deploy
Deploy → New Deployment → Web App → Execute as: Me → Access: Anyone → Deploy
4
Allow permissions
Google will ask to authorize → Click Authorize access → Choose your Gmail → Click Advanced → Go to (project) → Allow
5
Copy the URL & paste below
After deploy you'll get a Web App URL — copy it and paste in the box below
Web app URL: https://script.google.com/macros/s/XXXXX.../exec
