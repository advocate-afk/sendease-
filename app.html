🔗 Connect Your Gmail
One-time setup — 3 minutes. Your emails send directly from your own Gmail. Free forever via Google Apps Script.
Connected
1
Open Google Apps Script
Go to script.google.com (sign in with your Gmail) → Click New Project
2
Paste the Code
Delete everything in the editor → Copy the code from Code.gs → Paste it → Press Ctrl+S to save
📄 Code.gs → Select All → Delete → Paste → Ctrl+S
3
Deploy as Web App
Click Deploy (top right) → New Deployment → Type: Web App
Set Execute as: Me  |  Who has access: Anyone → Click Deploy
Deploy → New Deployment → Web App → Execute as: Me → Access: Anyone → Deploy
4
Allow Permissions
Google will ask for permission → Click Authorize access → Choose your Gmail account → Click Advanced → Go to (project name) → Allow
5
Copy the URL & Paste Below
After deploy, you'll see a Web App URL — copy it and paste below
